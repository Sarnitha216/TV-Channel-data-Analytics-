# TV Channel Data Analytics

## Project Overview
This project analyzes TV channel and entertainment data using Python, Pandas, and Matplotlib.

## Objectives
- Understand the TV channel dataset
- Check and clean data quality issues
- Perform statistical analysis
- Analyze channel-wise and show-category performance
- Identify popular shows and channels
- Visualize important insights

## Dataset
The dataset contains information about:
- Channel Name
- Language
- Channel Category
- Popular Show
- Show Category
- Number of Shows
- Average Viewers
- Average Rating
- Total Likes
- Social Media Followers
- YouTube Views
- HD Availability
- Years Active
- Subscription Fee
- Monthly Reach

## Data Cleaning
The following preprocessing tasks were performed:
- Checked missing values
- Checked duplicate records
- Checked invalid values
- Converted numerical columns stored as text into numeric format
- Handled missing/invalid values
- Saved the cleaned dataset

## Analysis Performed
- Basic statistical analysis
- Channel-wise analysis
- Show-category analysis
- Popularity analysis
- Final performance analysis

## Visualizations
- Average viewers by channel
- Average rating by channel
- Average viewers by show category
- Distribution of average viewers
- Boxplot of average viewers
- Boxplot of total likes
- Channel distribution

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
